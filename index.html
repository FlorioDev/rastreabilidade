📥 Importar Dados Legados (.db)
Selecione um arquivo .db (SQLite) do sistema antigo em Python — entrada.db, saida.db ou devolucao.db. O sistema identifica automaticamente o tipo pela tabela interna e importa todos os registros para a coleção correspondente no Firebase.

⚠️ Esta operação pode levar alguns minutos para arquivos grandes (milhares de registros) e não pode ser desfeita automaticamente. Evite importar o mesmo arquivo duas vezes (isso criaria registros duplicados).
